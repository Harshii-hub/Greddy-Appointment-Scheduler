🏥 Hospital Appointment Operations Portal
A Streamlit-based web application designed to manage hospital appointments efficiently.
This system allows users to add, view, and optimize patient schedules using a Greedy Algorithm (Activity Selection Problem) to avoid time conflicts.

🚀 Features
🔐 Secure Login System

📅 View All Appointments (Interactive Table)

➕ Add New Patient Appointments

⚡ AI-Based Schedule Optimizer

📊 Dashboard with Live Metrics

💾 SQLite Database Integration

🧠 Algorithm Used
This project uses a Greedy Algorithm to solve the Activity Selection Problem.

Appointments are sorted based on end time

The system selects appointments that do not overlap

Ensures maximum number of patients are scheduled efficiently

🛠️ Tech Stack
Frontend: Streamlit

Backend: Python

Database: SQLite

Data Handling: Pandas
